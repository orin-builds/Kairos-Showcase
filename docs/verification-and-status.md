**文档整理日期：2026-09-27。** 本页说明公开描述的依据类型与验证边界，不替代发行说明、当前设备验收或生产监控。

## 先区分三种证据

| 证据类型 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 当前可读取的源码、协议与测试文件 | 对应模块、规则和检查目标确实存在。 | 测试现在一定通过、当前手机安装了这些代码。 |
| 历史构建、测试与阶段报告 | 对应快照在记录的条件下完成过某项检查。 | 后续改动、其他设备或线上环境仍然自动满足相同结论。 |
| 本轮实际执行的验证 | 本轮命令、界面或运行结果所覆盖的内容。 | 超出环境与测试范围的泛化保证。 |

本次展示更新只读查阅了本地工程与资料，并整理公开文档。**没有为写 README 而启动 App 构建、访问真实学习数据库、运行设备操作或改变服务部署。**

## 已有材料如何支撑公开介绍

| 领域 | 本次查阅或定位到的依据类别 | 公开介绍可以据此说明什么 |
| --- | --- | --- |
| 任务与学习 | 任务呈现、日计划、学习模型和执行边界相关测试。 | 项目已有相应领域模型与测试，不只停留在产品想法。 |

| 数据兼容 | 覆盖历史结构与连续版本的迁移测试。 | 历史数据保留是工程的一部分，不以重新建库替代升级。 |
| App 守护与计时 | 限制状态机、保护规则、专注计时等测试与阶段记录。 | 对状态、边界与恢复有实现和验证关注；不能据此承诺所有设备都有效。 |
| Bridge / Server | 身份、校验、同步、归档、队列、恢复等组件及测试资料。 | 有服务器侧工程结构；不等于所有生产连接已经启用。 |
| GPT 协作 | 共同规则、总控/学科配置、输入输出与对抗性验收资料。 | 角色和结构化协作有明确约定；配置不等于远端会话已全部联通。 |
| Learning Runtime | 上下文、依赖读集与候选映射的适配说明。 | 候选与真实业务状态之间存在专门的适配工作，不靠复制聊天历史充当事实。 |

私有原始文件不在本仓库复制发布，因此这些条目是**项目方的整理说明，而不是读者可独立重跑的公开测试证据**。后续可用合成数据与脱敏演示补足外部可验证性。

## 成熟度应该按组件与路径判断

| 范围 | 当前公开表述 | 不作的保证 |
| --- | --- | --- |
| App 功能 | 存在实现与持续开发资料。 | 每项功能都通过当前设备的完整验收。 |
| 服务端组件 | 存在隔离验证与受条件约束的运行组件。 | 已开通所有真实上游、权限和自动写入能力。 |

| 对外使用 | 可阅读产品与技术文档。 | 已有公开服务、可安装发行版或完整开源源码。 |

## 需要怎样的测试才有说服力？

以下是按风险组织的验收清单，**不是本轮执行结果或全部通过声明**。

| 验证层 | 代表场景 | 要回答的问题 |
| --- | --- | --- |
| 领域规则 | 部分完成、重复结束、合法补充、乱序重放。 | 状态和奖励是否按既有规则变化？ |
| 数据迁移 | 不同历史结构升级、关联与余额保留、失败路径。 | 新功能是否破坏已有数据或凭空产生新事实？ |
| 规划与依赖 | 容量变化、材料变更、过期候选、相关/无关对象变化。 | 旧上下文上的候选是否被正确识别？ |
| 权限与角色 | 错误身份、范围不匹配、撤销授权、重复确认。 | 不被允许的动作是否在真实处理边界被拒绝？ |
| 同步与恢复 | 重复请求、晚到回执、网络中断、进程重启。 | 状态是否可解释、可核对，是否出现重复副作用？ |
| 设备行为 | 前后台切换、权限失效、服务恢复、实际交互。 | 主机测试之外的设备体验是否符合预期？ |
| 端到端 | 合成目标到候选、确认、应用、执行、反馈回流。 | 每一阶段是否有对应且可追溯的结果？ |

## 为什么暂时没有“通过了多少测试”和“提升了多少效率”？

历史报告包含不同日期、模块和构建变体的结果。把它们相加既不能代表独立用例数，也不能证明当前版本质量。

同样，任务完成率、专注时长、学习效果和用户规模需要各自可靠的测量方法，不能从源码数量或一次演示中推导。本仓库暂不提供这些数字。

## 公开证据的发布要求

- 使用专用示例账号与合成学习数据。
- 标注录制版本、日期、环境和演示范围。
- 清除通知、私人文件、设备标识、生产地址和凭据。
- 让截图、视频与说明对应，不把设计图当作真实界面。
- 对失败、限制和未覆盖路径保留必要说明。
- 只发布经过挑选的结果，不上传整份开发日志或私有 Git 历史。

这些要求保护个人信息，也让项目展示更可信。
